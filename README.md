# C Programming & Data Structures

A collection of C programs developed while practising
programming fundamentals and Data Structures and Algorithms.

## 📚 Topics Covered

- Singly Linked Lists
- Doubly Linked Lists
- Stacks
- Queues
- Input-Restricted Deque
- Output-Restricted Deque
- Quick Sort

## 🛠️ Technologies

- Language: C
- Editor: Visual Studio Code
- Compiler: GCC / Clang

## 🚀 Getting Started

1. Clone this repository.
2. Open a C file in your code editor.
3. Compile and run the program using a C compiler.

Example:

clang quickSort.c -o quickSort
./quickSort
